# ESP32 Motion Tamagotchi

**ESP32 + MPU-6050 6축 모션 센서 + 0.96인치 IPS LCD** 기반의 제스처 인터랙션 휴대용 다마고치 프로젝트입니다.  
단순 버튼 입력을 넘어 **기울이기·흔들기·걷기(만보기) 등 실제 움직임으로 캐릭터와 교감**하고, 퍼블릭 저장소 운영을 위해 **펌웨어 로직과 커스텀 그래픽 에셋 빌드 파이프라인을 완전히 분리**하여 설계했습니다.

---

## 주요 기능 (Features)

* **제스처 기반 동행 시스템 (MPU-6050):**
  * 가속도·자이로 센서 데이터로 휴대 및 움직임(걷기/흔들기/쓰다듬기)을 감지해 **동행 게이지(Companion Gauge)**를 채웁니다.
  * 동행 게이지가 일정 수준 이상 쌓이면 캐릭터의 컨디션이 회복되고 자동으로 주변 청소를 도와주는 연출이 발동합니다.
* **직관적인 3버튼 + 하드웨어 리셋 UX:**
  * **A 버튼 (왼쪽):** 메뉴 이동 / 선택 커서 이동
  * **B 버튼 (가운데):** 확인 / 밥 주기 / 놀아주기 실행
  * **C 버튼 (오른쪽):** 취소 / 이전 화면 / 상태창 토글
  * **A + C 동시 롱프레스 (3초):** 세이브 데이터 초기화 및 새 캐릭터 뽑기(가챠) 리셋
* **6가지 상태 머신 & 2프레임 도트 애니메이션:**
  * `IDLE`(대기), `WALK`(산책), `EAT`(식사), `HAPPY`(기쁨), `DIRTY`(청소 필요), `SLEEP`(수면) 상태 전환 및 앵커 고정형 2프레임 스프라이트 루프 애니메이션을 지원합니다.
* **저작권 안전 에셋 파이프라인 (Copyright-Safe Asset Pipeline):**
  * 퍼블릭 레포지토리에는 C++ 펌웨어 코어, 변환 스크립트, 기본 플레이스홀더(`sprites_default.h`)만 포함됩니다.
  * 개인 소장용 커스텀 도트 에셋(`assets/raw/*.png`) 및 변환된 헤더(`firmware/src/sprites.h`)는 `.gitignore`로 분리되어 로컬 환경에서만 빌드됩니다.

### 부품 구매 및 조립 시 필수 주의사항

1. **납땜 여부 확인 (`핀헤더 납땜 옵션`):**
   * 인두기가 없다면 보드(`ESP32-C3 SuperMini`), `ST7735S LCD`, `MPU-6050` 구매 시 반드시 **"핀헤더 납땜 완료"** 옵션을 선택하세요. 핀이 안 꽂혀 있으면 브레드보드에 꽂을 수 없습니다.
2. **전압 주의 (`3.3V` 전용):**
   * `ST7735S LCD`와 `MPU-6050`은 반드시 보드의 **`3.3V` 핀**에 연결해야 합니다. `5V` 핀에 잘못 연결하면 부품이 탈 수 있습니다.
3. **배터리 극성(`+`/`-`) 및 충전 전류 주의:**
   * 배터리 선을 `TP4056` 모듈에 연결할 때 **빨간선(`B+`)과 검은선(`B-`)이 반대로 꽂히면 즉시 기판이 손상**됩니다.
   * 시중에 파는 `TP4056` 모듈은 기본 충전 전류가 `1A`로 설정되어 있어 300~500mAh 소형 배터리에 다소 높을 수 있으므로, 장기간 사용 시 모듈의 `R3(RPROG)` 저항을 교체하거나 보호회로(PCM)가 내장된 배터리를 사용하세요.
4. **LCD 핀 이름 확인 (`SCL / SDA` 표기):**
   * 일부 `0.96인치 ST7735S` 모듈은 SPI 통신인데도 핀 이름이 I2C처럼 `SCL`, `SDA`로 적혀 있습니다. 이는 불량이 아니며 각각 **`SCL = SCK(클럭)`**, **`SDA = MOSI(데이터)`**로 연결하면 정상 작동합니다.
5. **업로드용 USB-C 케이블 확인:**
   * 충전 전용 케이블이 아닌 **데이터 전송이 가능한 USB-C 케이블**을 사용해야 PC에서 펌웨어 업로드가 인식됩니다.
